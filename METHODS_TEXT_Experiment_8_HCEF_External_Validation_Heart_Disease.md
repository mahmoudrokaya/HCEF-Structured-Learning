
### Experiment 8: External Cross-Domain Validation on the UCI Heart Disease Dataset

The eighth experiment evaluated the proposed HCE-F framework on the UCI Heart Disease Dataset as a second far-domain external validation task. This dataset differs from the Jena climate forecasting task and the Breast Cancer Wisconsin dataset in clinical feature type, sample size, missing-value structure, and disease-risk semantics. The prediction task was formulated as binary classification, where the original UCI disease severity target was converted into a binary indicator representing absence or presence of heart disease.

The dataset was loaded from the local external validation folder, cleaned to handle common UCI missing-value markers, and processed using automatic target detection. Numerical variables were retained, categorical or non-numeric variables were label-encoded when necessary, and missing values were median-imputed. The data were split into stratified training, validation, and test partitions. HCE-F was implemented as a tabular classifier using a tensorized residual encoder, residual-gated feature stabilization, supervised contrastive projection, and two-head probabilistic ensemble classification. Performance was evaluated using accuracy, precision, recall, F1-score, ROC-AUC, PR-AUC, confusion matrix analysis, ROC curves, and precision-recall curves. Classical machine-learning baselines were trained under the same split to contextualize external validation performance.
